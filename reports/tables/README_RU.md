# Как читать итоговые таблицы

CSV-файлы используют стабильные технические имена столбцов.
В ноутбуке эти же таблицы показаны с русскими подписями.

| Файл | Содержание |
|---|---|
| experiment_metrics.csv | Размеры групп, покупки, конверсия, посещения и выручка |
| experiment_effects.csv | Средние эффекты каждого письма относительно контроля |
| balance.csv | Баланс признаков между группами |
| model_selection.csv | Сравнение моделей на валидации |
| validation_policies.csv | Стратегии на валидации |
| test_policies.csv | Стратегии на отдельной тестовой выборке |
| test_paired_comparisons.csv | Парные разницы стратегий со случайной рассылкой |
| uplift_curves.csv | Кривые ранжирования для письма с мужскими товарами против контроля |
| exploratory_channels.csv | Исследовательские сравнения по каналам |

## Общие поля

| Поле | Значение |
|---|---|
| segment / arm | Группа эксперимента / тип письма; переводы — в DATA_SOURCES.md |
| action | 0 — без письма, 1 — письмо с мужскими товарами, 2 — письмо с женскими товарами |
| customers / n | Число клиентов в группе / оцениваемой выборке |
| purchases | Число покупок |
| conversion_rate / visit_rate | Доля клиентов с покупкой / посещением |
| revenue_per_customer / total_revenue | Выручка на клиента / всего, доллары США |
| outcome | conversion — покупка, visit — посещение, spend — расходы |
| control_mean / treatment_mean | Средний исход в контроле / группе письма |
| estimate | Оценка эффекта; вероятность на одного клиента, если не указано другое |
| se | Стандартная ошибка оценки |
| low / high | Нижняя / верхняя граница индивидуального 95% доверительного интервала |
| pvalue | p-значение без поправки |
| pvalue_holm | p-значение с поправкой Холма |
| feature / standardized_difference | Признак / стандартизованная разность средних |
| model / mode | Кандидат модели / вид стратегии |
| strategy / label | Техническое имя стратегии / русская подпись |
| coverage | Заданная доля клиентов для контакта |
| actual_coverage | Фактическая доля контактов после округления бюджета вниз |
| ipw_estimate | Оценка эффекта по IPW без моделей исходов |
| mens_share / womens_share | Доли всей аудитории, которым стратегия назначает соответствующее письмо |
| comparator | Стратегия сравнения; random_mens — случайная рассылка письма с мужскими товарами |
| gain / random | Накопленный эффект IPW / случайная диагональ на кривой ранжирования |
| channel | Канал прежних покупок |
| treated_n / control_n | Число клиентов группы письма / контроля в сегменте |
| incremental_conversion | Разница конверсий письма и контроля |
| channel_rank | Место канала по оценке эффекта; только исследовательская характеристика |

Чтобы получить дополнительные покупки **на 10 000 клиентов**,
умножь estimate, se, low и high в таблицах стратегий на 10 000.
Эффект конверсии в процентных пунктах — estimate × 100.
Выручка и расходы уже выражены в долларах США.

## Стратегии и модели

| Идентификатор | Название |
|---|---|
| random_mens | Случайный выбор клиентов для письма с мужскими товарами |
| response | Ранжирование по вероятности покупки после письма с мужскими товарами |
| rule | Правило недавних покупок |
| uplift | Аплифт письма с мужскими товарами относительно отсутствия рассылки |
| multiarm | Аплифт с выбором лучшего из двух писем |
| logit_0.1 / logit_1 | Логистическая регрессия с C=0,1 / C=1 |
| boost | Градиентный бустинг |

В test_paired_comparisons.csv estimate — **разница со случайной рассылкой**,
а не эффект относительно отсутствия писем. Её интервал используется для проверки
преимущества стратегий; пересечение отдельных интервалов в test_policies.csv
не заменяет парного сравнения.

Исследовательские результаты других охватов и каналов не доказывают, что найден
победитель. Основное сравнение заранее зафиксировано при охвате 20%.
