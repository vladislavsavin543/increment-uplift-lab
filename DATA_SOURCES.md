## Что содержится в данных

64 000 строк, 12 полей, без уникального идентификатора клиента.
Признаки описывают предшествующие 12 месяцев, исходы — две недели после рассылки.
Три группы назначены случайно. Письма содержат письмо с мужскими или женскими товарами;
пол клиента неизвестен.

В зеркале сохранено написание категории **Surburban**. Мы используем её как
категориальное значение и не исправляем и не объединяем её незаметно.

## Словарь исходных полей

| Поле | Значение |
|---|---|
| recency | Месяцев с предыдущей покупки |
| history_segment | Группа расходов за прошлый год; исключена из модели как избыточный признак |
| history | Расходы за прошлый год, доллары США |
| mens / womens | Прежние покупки мужского / письма с женскими товарами; не пол клиента |
| newbie | Новый клиент в течение предыдущего года |
| zip_code | Тип местности: Rural — сельская, Urban — городская, Surburban — пригородная; это не почтовый индекс |
| channel | Канал прошлых покупок: Phone — телефон, Web — интернет, Multichannel — несколько каналов |
| segment | Случайно назначенная группа рассылки |
| visit | Посещение в течение двух недель после рассылки |
| conversion | Покупка в течение двух недель после рассылки |
| spend | Наблюдаемые расходы после рассылки, доллары США |

Значения segment: **No E-Mail** — без письма, **Mens E-Mail** — письмо с мужскими товарами,
**Womens E-Mail** — письмо с женскими товарами.

Нет данных о стоимости кампании, марже, скидках, времени отдельных покупок,
долгосрочных отписках или будущей ценности клиента. Поэтому прибыль калькулятора
основана на заданных пользователем допущениях, а не на фактических расходах.

## Технические поля проекта

- source_row — номер исходной строки CSV, а не идентификатор человека.
- action — назначенное действие: 0 — без письма, 1 — письмо с мужскими товарами, 2 — письмо с женскими товарами.
- split — выборка: train — обучение, validation — валидация, test — тест.
- log_history — преобразование log1p(history) для моделирования.
- mu_0 / mu_1 / mu_2 — прогнозы моделей исходов для оценки AIPW.
- binary_p_0 / binary_p_1 / binary_p_2 — прогнозы моделей стратегии письма с мужскими товарами.
- multi_p_0 / multi_p_1 / multi_p_2 — прогнозы моделей стратегии выбора письма.

Имена CSV-полей и ключей JSON сохранены для воспроизводимости.
